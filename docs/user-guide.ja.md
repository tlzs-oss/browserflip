# BrowserFlip 操作説明

BrowserFlip の使い方を説明します。対象は v0.2.0 です(動作を確認しているのは Windows 11 のみです)。設計の詳細は [desktop-design.ja.md](desktop-design.ja.md) を参照してください。

> 画面上の名称は日本語表示のものです。言語は画面右上の言語の選択欄で English / 日本語 / 简体中文 に切り替えられます。

## 0. 画面の構成(通常画面)

通常画面は高さ約 350 DIP のコンパクトなウィンドウです。内容に合わせて高さが変わり、画面の作業領域を超える場合はスクロールします。幅は表示言語に合わせて自動で決まり(520 DIP 以上。日本語では少し広くなります)、枠をドラッグして変えた幅は次回以降も保持されます。ウィンドウが狭いときは、ヘッダーのキャッチコピーが折り返し、さらに狭いとボタンが 2 段目に移ります(ボタンは隠れません)。

| 場所 | 内容 |
|---|---|
| ヘッダー左 | アプリ アイコン、名称、キャッチコピー |
| ヘッダー右 | 言語の選択欄、**ピン**(常に手前に表示)、**コンパクトバーに切り替え**、**再読み込み**(F5) |
| 帯 | 現在の既定のブラウザー(HTTP と HTTPS が異なる場合は黄色の警告) |
| カード(2 列) | ブラウザーのアイコン・名前と状態(「既定」バッジ、または「クリックして既定に設定」)。詳しい案内はカードにマウスを重ねると表示されます |
| 表示オプション | 折りたたみ式。開くとウィンドウが伸び、内容が隠れることはありません |
| 下部 | 説明文と「既定のアプリを開く」 |

ライト / ダーク / システムに合わせたテーマに対応し、ボタンや選択欄も Windows 11 の見た目で表示されます(ハイ コントラスト時はシステムの配色)。

## 1. 基本操作(既定のブラウザーを変更する)

1. BrowserFlip を起動します。インストール済みのブラウザーがカードで表示され、現在の既定のブラウザーには「既定」バッジが付きます。
2. 既定にしたいブラウザーのカードをクリックします(キーボードでは Tab で選んで Enter / Space)。
3. Windows の設定が開きます。
   - Windows 11(2023 年 4 月の更新プログラム以降): そのブラウザーのページで **「既定値に設定」** をクリックします。
   - それより古い Windows 11、または Windows 10(v0.2.0 では未検証・動作保証対象外): 「既定のアプリ」でブラウザーを選択します。
4. BrowserFlip に戻ると、バッジが新しい既定のブラウザーに移動し、「{ブラウザー名} が既定のブラウザーになりました。」と表示されます。

BrowserFlip が既定のブラウザーを勝手に変更することはありません。変更は必ず Windows の設定画面であなたが確定します。

## 2. 常に手前に表示(最前面)

- 通常画面の右上にある **ピン ボタン** をクリックすると、BrowserFlip が他のウィンドウより手前に表示されます。もう一度クリックすると解除します。
  - OFF のとき: 通常の背景に、斜め(45°)に傾いた灰色のピン。ツールチップは「常に手前に表示する」です。
  - ON のとき: 青い背景に、まっすぐ立った白いピン。ツールチップは「常に手前に表示を解除」です。
  - キーボードでは Tab でピンを選び、Space / Enter で切り替えます。スクリーン リーダーにはトグル ボタンとして、オン / オフの状態とともに読み上げられます。
- コンパクトバーのピン ボタン(通常画面と同じデザイン)、右クリック メニュー / 通知領域メニューの「常に手前に表示」でも切り替えられます。切り替えてもバーの大きさや並びは変わりません。
- 設定は保存され、次回起動時も維持されます。通常画面とコンパクトバーの両方に適用され、バーが画面端にドッキングしているかどうかとは関係ありません(ドッキング、自動的に隠す、常に手前に表示はそれぞれ独立しています)。
- OFF のときでも、ドッキング中のバーが展開するときは他のウィンドウの上に表示されます(アクティブにはなりません)。収納中の細い帯は最大化したウィンドウの後ろに隠れることがありますが、その端にマウスを近づければ展開します。
- 全画面のアプリ(動画、ゲーム、プレゼンテーションなど)を使っている間は、操作を妨げないよう最前面表示が **一時的に解除** されます。全画面を終えると元に戻ります。

## 3. コンパクトバー

- 通常画面の右上の **「コンパクトバーに切り替え」** ボタンをクリックすると、小さなツールバー(コンパクトバー)になります。バーは通常画面があった場所の中央に、表示オプションの「ドッキングしていないときの向き」でフローティング表示されます(そのモニターの画面内に収まり、隅や別のモニターへ移ることはありません)。それまでバーを画面端にドッキングしていた場合も、このボタンではフローティングになります。画面端にドッキングするには §4 のとおりドラッグします。
- バーには左から(縦向きでは上から)次のボタンが並びます。
  - **BrowserFlip アイコン**: 「通常画面に戻る」。通常画面は前の位置と幅で表示されます(そのモニターが外されていれば、表示中のモニターに移ります)。
  - **ピン**: 常に手前に表示の切り替え
  - **ブラウザーのアイコン**: クリックすると通常画面と同じように Windows の設定が開きます。既定のブラウザーは枠と背景色で強調されます。マウスを重ねると名前と状態が表示されます。
  - **歯車**: 「表示オプション」(通常画面に戻り、表示オプションを開きます)
- バーの長さはブラウザーの数に合わせて決まります。画面に収まらないほどブラウザーが多い場合は、バーに沿ってスクロール バーが表示され、マウス ホイールでもスクロールできます。
- バーの何もない部分を右クリックすると、メニュー(§6 と同じ項目)が開きます。
- バーには案内メッセージは表示されません。設定画面から戻った後の結果は、既定のブラウザーの強調表示が切り替わることで確認できます。詳しいメッセージを見たいときは通常画面に戻ってください。エラー(ブラウザーが見つからない等)が起きた場合は、自動的に通常画面に戻って内容を表示します。
- バーには閉じるボタンはありません。バーを選択して Alt+F4 を押すと、フローティングのバーは隠れて通知領域アイコンだけになり、ドッキング中のバーはその端に収納されます(アプリは終了しません。§6)。終了するには右クリック メニューまたは通知領域の「BrowserFlip を終了」を使います。

### 表示オプション

通常画面の下部にある **「表示オプション」** を開くと、次の項目を変更できます。

| 項目 | 内容 |
| --- | --- |
| テーマ | システム / ライト / ダーク |
| バーのサイズ | 小 / 中 |
| ドッキングしていないときの向き | 横 / 縦(既定は横) |

「ドッキングしていないときの向き」の下には、「コンパクトバーを画面端にドッキングしていないときの向きです。バーを画面端へドラッグするとドッキングし、上下の端では横、左右の端では縦に自動で切り替わります。」と表示されます。この設定はバーが画面端から離れている(フローティング)ときだけ使われ、ドッキング中のバーの向きは変わりません。

ドッキングする端は §4 のとおりドラッグで決めます。自動的に隠す機能(§5)と通知領域アイコン(§6)は常に有効で、オプションはありません。

## 4. ドッキングとドラッグでのスナップ

- バーを画面端にドッキングするのは、バー(または通常画面)を画面端へドラッグしたときです。コンパクトバー ボタンで切り替えた直後のバーはフローティングです。
- ドッキングする端は **ドラッグだけ** で決まります(メニューやオプションはありません)。バーの何もない部分(ボタン以外)をドラッグすると移動できます。
  - ドラッグ中は、ドッキングする場所と向きが **半透明の枠**(アクセント色)で表示されます。
  - マウス カーソルが画面の端の近く(約 24 ピクセル(100% 表示時)以内)にある状態で離すと、その端に **スナップ** してドッキングします。端を越えて(タスクバーの上などに)カーソルを動かした場合や、バーを端より外へ押し出した場合も、その端にドッキングします。
  - 端から離れた場所で離すと、ドッキングが解除されて自由な位置(フローティング)になり、その位置が保存されます。フローティングのバーが勝手に端へ戻ることはありません。
- バーの向きは自動で決まります。上下の端では **横**、左右の端では **縦**、フローティング中は表示オプションの「ドッキングしていないときの向き」です。向きが変わると、大きさと位置が画面内に収まるように調整されます。
- バーはタスクバーを除いた画面の内側に、端から少し離して表示されます。他のウィンドウの配置や最大化サイズは変わりません。
- 複数のモニターがある場合は、ドラッグを終えたときにマウス カーソルがあるモニターの端にドッキングします。ドッキングした端・モニター・端に沿った位置は保存され、次回もそこに表示されます(モニターが見つからない場合はメイン モニター)。

### 通常画面を画面端へドラッグしてドッキングする

- 通常画面をタイトル バーでドラッグし、**マウス カーソルを画面の端に押し当てたまま**(端から 2 ピクセル以内、またはタスクバーの上まで)離すと、そのモニターのその端にドッキングしたコンパクトバーに切り替わります。左右の端では縦、上下の端では横です。
- バーは最初から収納された状態(画面端の細い帯)で表示されます。その端にマウスを近づけると展開します。
- ドラッグ中にカーソルが端に押し当てられると、ドッキング先が半透明の枠で表示されます。枠が出ていない状態で離せば、普通の移動です。
- カーソルを端に押し当てない普通の移動や、ウィンドウのサイズ変更では切り替わりません。
- Windows のスナップ機能で通常画面の位置や大きさが変わった場合でも、通常画面はドラッグ前の位置に戻されます。次に通常画面を表示したときはその位置に表示されます。

## 5. 自動的に隠す

画面端にドッキングしたバーは、常に自動的に隠れます(オプションはありません)。フローティング中のバーは隠れません。

- マウスがバーから離れて約 0.45 秒たつと、バーがフェードして収納され、画面の端にバーと同じ長さの細い **帯**(アクセント色、厚さ 3〜5 ピクセル)だけが残ります。
- バーが表示された直後、ドラッグの直後、通知領域から呼び出した直後は、約 1.5 秒間は収納されません。
- 次の間は収納されません: バーの上でマウス ボタンを押している間、ドラッグ中、メニューが開いている間、バーの上で実際にキーボードを操作している間(Tab・矢印・Enter などを押した後。マウスでバーを押すと解除。修飾キー・音量 / メディア キー・PrintScreen は含まない。通知領域から Enter で表示した場合も含む)。
- モニターの追加・取り外し、解像度・拡大率やタスクバーの変更、スリープからの復帰の後は、収納されていたバーがいったん表示されます。
- ブラウザーをクリックして Windows の設定が開いた後は、設定画面の操作を邪魔しないようにバーは通常どおり収納されます。既定の変更の確認は裏で続きます。

### 収納されたバーを呼び出す

- **バーのある画面端にマウスを近づける**: 帯の上だけでなく、バーがあった範囲(端に沿ったバーの全長)のどこでも、端から十数ピクセル以内に少し(約 0.1 秒)留まるとフェードして展開します。通り過ぎただけでは開きません。隣のモニターと接している端では、隣のモニターへ少しはみ出しても展開します。
- **帯をクリック** する(キーボードでは Enter)と、すぐに展開します。
- **通知領域アイコンを左クリック** するか、メニューの「BrowserFlip を表示」/「コンパクトバーを表示」を選ぶと展開します。

マウスを重ねて開いた場合は、マウスが離れるとまた収納されます。

## 6. 通知領域アイコン

BrowserFlip の実行中は、通知領域(タスクバー右端)に常にアイコンが表示されます(オプションはありません)。アイコンにマウスを重ねると、現在の既定のブラウザーが表示されます。

- **左クリック**: 使っていた画面を元の場所に戻します。通常画面なら通常画面(最小化していた場合も)、フローティングのバーなら元の位置・向きのバー、ドッキング中のバーなら展開したバーです。
- **右クリック**: メニューを表示します。コンパクトバーを右クリックしても同じメニューが開きます。

| メニュー項目 | 動作 |
| --- | --- |
| **BrowserFlip を表示**(太字) | 使っていた画面を元の場所に戻す(左クリックと同じ) |
| コンパクトバーを表示 | コンパクトバーを表示して展開。通常画面から切り替える場合は、コンパクトバー ボタンと同じく通常画面の位置にフローティングで表示 |
| 設定… | 通常画面を開き、表示オプションを表示 |
| 常に手前に表示 | 最前面表示の切り替え(チェック付き) |
| BrowserFlip を終了 | BrowserFlip を終了 |

### 閉じる・最小化の動作

| 操作 | 結果 |
| --- | --- |
| 通常画面の × | BrowserFlip のウィンドウをすべて隠し、通知領域アイコンだけになります。バーは表示されず、表示モードの切り替えも終了もしません。表示モード・ドッキング状態・位置は変わりません |
| 通常画面の — | 通常どおりタスクバーに最小化します |
| フローティングのバーで Alt+F4 | バーを隠し、通知領域アイコンだけになります |
| ドッキング中のバーで Alt+F4 | 同じ端・モニター・位置のまま収納され、細い帯(3〜5 ピクセル)になります。マウスを近づけると展開します |
| 通知領域アイコンの左クリック(BrowserFlip の再起動も同じ) | 使っていた画面を元の場所に戻します(通常画面は最小化からも、フローティングのバーは元の位置・向きで、ドッキング中のバーは展開して) |
| 通知領域メニューの「BrowserFlip を終了」 | BrowserFlip を終了します(通知領域アイコン・ウィンドウ・タイマーを解放) |

通知領域アイコンだけになった状態は、実行中だけのものです。保存されている表示モード(通常画面 / コンパクトバー)は変わらないため、BrowserFlip を再起動すると、保存されている画面で起動します。

- BrowserFlip を終了するのは、メニューの「BrowserFlip を終了」を選んだときと、Windows のサインアウト / シャットダウンのときだけです。
- BrowserFlip は同時に 1 つしか起動しません。実行中にもう一度起動すると、実行中の BrowserFlip が前面に表示され、新しく起動したほうはすぐに終了します(通知領域アイコンが 2 つになることはありません)。
- エクスプローラーが再起動しても、アイコンは自動的に再表示されます。

## 7. 設定の保存場所とリセット

- 設定は次のファイルに自動保存されます(変更するたびに保存)。

  ```text
  %LOCALAPPDATA%\BrowserFlip\settings.json
  ```

- 保存される内容: 言語、テーマ、表示モード(通常 / コンパクト)、常に手前に表示、ドッキングの有無・端・位置・モニター、バーのサイズと向き、通常画面とバーの位置・大きさ。
- **リセット方法**: BrowserFlip を終了してから `settings.json` を削除します。次回起動時はすべて既定値(通常画面で起動、最前面 OFF、コンパクトバー ボタンでは通常画面の位置にフローティング表示、通知領域アイコンは常に表示)で起動します。

  ```powershell
  Remove-Item "$env:LOCALAPPDATA\BrowserFlip\settings.json"
  ```

- ファイルの一部の値が壊れていても、その項目だけが既定値に戻り、ほかの設定は維持されます。v0.1 の設定ファイルもそのまま使えます。
- BrowserFlip はこのファイル以外に書き込みを行わず、レジストリも変更しません。

## 8. トラブルシューティング

**コンパクトバーが見えない / どこにあるか分からない**

1. 通知領域アイコンを左クリックするか、右クリックして「コンパクトバーを表示」を選びます。BrowserFlip をもう一度起動しても、使っていた画面が元の場所に表示されます。× で閉じた後は、BrowserFlip のウィンドウは表示されず通知領域アイコンだけになります(§6)。
2. 画面の端に細い帯があれば、自動的に隠すで収納されています。その端にマウスを近づけるか、帯をクリックしてください。
3. それでも見つからない場合は、通知領域メニューの「BrowserFlip を終了」で終了し(タスク マネージャーから終了してもかまいません)、`settings.json` を削除してから起動し直してください(§7)。通常画面で起動します。

**モニターを外したらウィンドウが消えた**

モニターの接続・切断、解像度・拡大率の変更、スリープからの復帰、タスクバーの位置変更の後は、BrowserFlip が自動的に画面内に配置し直します。表示されない場合は上と同じ手順で呼び出してください。

**最前面にしているのに、他のウィンドウの後ろに隠れる**

全画面のアプリやプレゼンテーションの実行中は、最前面表示が一時的に解除されます(仕様です)。全画面を終えると、約 1 秒以内に最前面に戻ります。ピン ボタンが ON(青い背景に白いピン)になっているかも確認してください。ドッキング中のバーも、「常に手前に表示」が OFF なら最前面にはなりません。

**最大化したウィンドウにバーが重なる**

ドッキングしたバーは画面の表示領域を予約しないため、展開するとほかのウィンドウの上に重なります。ドッキング中のバーは自動的に隠れるので、マウスを離せば細い帯だけになります。気になる場合は、バーを別の端やモニターへドラッグしてください。

**通常画面を動かしただけなのにバーに切り替わった**

通常画面をドラッグしてカーソルを画面端に押し当てたまま離すと、その端にドッキングしたバーに切り替わります(§4)。ドラッグ中に半透明の枠が出たら、カーソルを端から少し離してから離してください。通常画面に戻るには、端にマウスを近づけてバーを展開し、アプリ アイコンのボタンをクリックします。

**バーがすぐに隠れてしまう / 隠れない**

ドッキング中のバーは、マウスがバーから離れて約 0.45 秒後に収納します。バーの上で実際にキーボードを操作している間(Tab・矢印・Enter などを押した後。マウスでバーを押すと解除。修飾キー・音量 / メディア キー・PrintScreen は含まない。通知領域から Enter で表示した場合も含む)やメニューを開いている間は収納されません。隠したくない場合は、バーを画面の端から離れた場所へドラッグしてフローティングにしてください(フローティング中は隠れません)。

**「ドッキングしていないときの向き」を変えてもバーの向きが変わらない**

バーが画面端にドッキングしている間は、向きは端によって決まります(上下は横、左右は縦)。この設定はフローティング中のバーにだけ適用されます。

**× ボタンで閉じたのに終了しない**

仕様です。通常画面の × で閉じると、BrowserFlip のウィンドウはすべて隠れ、通知領域アイコンだけで動作を続けます(コンパクトバーに閉じるボタンはありません)。通知領域アイコンの左クリックで元の画面に戻ります。完全に終了するには、通知領域アイコン(またはコンパクトバー)を右クリックして「BrowserFlip を終了」を選びます。

**設定画面から戻ってもバッジが変わらない**

コンパクトバー使用中は、変更が約 1.5 秒間隔の確認で反映されます。少し待つか、通常画面に戻って「再読み込み」(F5)をしてください。そのほかの問題は [README](../README.ja.md) の「よくある質問」を参照してください。

## 9. キーボード操作

| 場所 | キー | 動作 |
| --- | --- | --- |
| 通常画面 | Tab / Shift+Tab | カードやボタンの間を移動 |
| 通常画面 | Enter / Space | 選択中のカード・ボタンを実行 |
| 通常画面 | F5 | 再読み込み |
| 通常画面 / コンパクトバー | Tab でピンを選択 → Space / Enter | 常に手前に表示の切り替え |
| コンパクトバー | Tab / Shift+Tab | バーのボタン・ブラウザーの間を移動 |
| コンパクトバー | Enter / Space | 選択中のボタンを実行 |
| コンパクトバー | アプリケーション キー / Shift+F10 | メニューを開く |
| コンパクトバー | Alt+F4 | フローティングは通知領域へ、ドッキング中は端に収納 |
| 収納時の帯 | Enter / Space | バーを展開 |
| メニュー | ↑ / ↓、Enter、Esc | 項目の選択、実行、閉じる |
| 通知領域 | Win+B → 矢印キーで BrowserFlip を選択 → Enter | 使っていた画面を元の場所に表示 |
| 通知領域 | Win+B → 選択 → アプリケーション キー / Shift+F10 | メニューを開く |

バーの上で実際にキーボードを操作している間(Tab・矢印・Enter などを押した後。マウスでバーを押すと解除。修飾キー・音量 / メディア キー・PrintScreen は含まない。通知領域から Enter で表示した場合も含む)は、自動的に隠す機能は収納しません。BrowserFlip が自分でバーを前面に出しただけ(通知領域のクリックなど)では、キーボード操作とはみなしません。
