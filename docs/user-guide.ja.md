# BrowserFlip 操作説明

BrowserFlip の使い方を説明します。対象は v0.2(未リリース)です。設計の詳細は [desktop-design.ja.md](desktop-design.ja.md) を参照してください。

> 画面上の名称は日本語表示のものです。言語は画面右上の言語の選択欄で English / 日本語 / 简体中文 に切り替えられます。

## 1. 基本操作(既定のブラウザーを変更する)

1. BrowserFlip を起動します。インストール済みのブラウザーがカードで表示され、現在の既定のブラウザーには「既定」バッジが付きます。
2. 既定にしたいブラウザーのカードをクリックします(キーボードでは Tab で選んで Enter / Space)。
3. Windows の設定が開きます。
   - Windows 11(2023 年 4 月の更新プログラム以降): そのブラウザーのページで **「既定値に設定」** をクリックします。
   - Windows 10 など: 「既定のアプリ」で「Web ブラウザー」を選び、ブラウザーを選択します。
4. BrowserFlip に戻ると、バッジが新しい既定のブラウザーに移動し、「{ブラウザー名} が既定のブラウザーになりました。」と表示されます。

BrowserFlip が既定のブラウザーを勝手に変更することはありません。変更は必ず Windows の設定画面であなたが確定します。

## 2. 常に手前に表示(最前面)

- 通常画面の右上にある **ピン ボタン**(ツールチップ「常に手前に表示（置頂）」)をクリックすると、BrowserFlip が他のウィンドウより手前に表示されます。もう一度クリックすると解除します。
- コンパクトバーのピン ボタン、右クリック メニュー / 通知領域メニューの「常に手前に表示」でも切り替えられます。
- 設定は保存され、次回起動時も維持されます。通常画面とコンパクトバーの両方に適用されます。
- 全画面のアプリ(動画、ゲーム、プレゼンテーションなど)を使っている間は、操作を妨げないよう最前面表示が **一時的に解除** されます。全画面を終えると元に戻ります。

## 3. コンパクトバー

- 通常画面の右上の **「コンパクトバーに切り替え」** ボタンをクリックすると、通常画面が閉じて小さなツールバーになります。
- バーには左から(縦向きでは上から)次のボタンが並びます。
  - **BrowserFlip アイコン**: 「通常画面に戻る」
  - **ピン**: 常に手前に表示の切り替え
  - **ブラウザーのアイコン**: クリックすると通常画面と同じように Windows の設定が開きます。既定のブラウザーは枠と背景色で強調されます。マウスを重ねると名前と状態が表示されます。
  - **歯車**: 「表示オプション」(通常画面に戻り、表示オプションを開きます)
- ブラウザーが多くてバーに収まらない場合は、マウス ホイールでスクロールできます。
- バーの何もない部分を右クリックすると、メニュー(§6 と同じ項目)が開きます。
- バーには案内メッセージは表示されません。設定画面から戻った後の結果は、既定のブラウザーの強調表示が切り替わることで確認できます。詳しいメッセージを見たいときは通常画面に戻ってください。エラー(ブラウザーが見つからない等)が起きた場合は、自動的に通常画面に戻って内容を表示します。
- バーを選択して Alt+F4 を押すと、バーは通常画面に切り替わります(アプリは終了しません)。終了するには右クリック メニューまたは通知領域の「終了」を使います。

### 表示オプション

通常画面の下部にある **「表示オプション」** を開くと、次の項目を変更できます。

| 項目 | 内容 |
| --- | --- |
| コンパクトバーを画面端にドッキング | バーを画面の端に固定します |
| 位置 | ドッキングする端(左 / 右 / 上 / 下) |
| ドッキング中は自動的に隠す（マウス接近で表示） | §5 を参照 |
| 通知領域にアイコンを表示 | §6 を参照(既定 ON) |
| ウィンドウを閉じても通知領域で動作を継続 | §6 を参照(既定 OFF) |
| テーマ | システム / ライト / ダーク |
| バーのサイズ | 小 / 中 |
| ドッキングしていないときの向き | 横 / 縦 |

## 4. ドッキングとドラッグでのスナップ

- **ドッキング**: 表示オプションの「コンパクトバーを画面端にドッキング」を ON にするか、メニューの「ドッキング位置」で左・右・上・下を選びます。左右では縦向き、上下では横向きのバーになります。
- バーはタスクバーを除いた画面の内側に、端から少し離して表示されます。他のウィンドウの配置や最大化サイズは変わりません。
- **ドラッグ**: バーの何もない部分(ボタン以外)をドラッグすると移動できます。
  - 画面の端の近く(約 24 ピクセル(100% 表示時)以内)で離すと、その端に **スナップ** してドッキングします。端に沿った位置も保存されます。
  - 端から離れた場所で離すと、ドッキングが解除されて自由な位置(フローティング)になり、その位置が保存されます。
- 複数のモニターがある場合は、バーの中心があるモニターの端にスナップします。ドッキング先のモニターは保存され、次回もそのモニターに表示されます(モニターが見つからない場合はメイン モニター)。

## 5. 自動的に隠す

ドッキング中だけ使えます。表示オプションの「ドッキング中は自動的に隠す（マウス接近で表示）」か、メニューの「自動的に隠す」で ON にします。

- マウスがバーから離れて約 0.6 秒たつと、バーが画面の端に収納され、細い **タブ**(つまみ)だけが残ります。
- 有効にした直後や、バーを呼び出した直後は約 1.5 秒間は収納されません。
- 次の間は収納されません: バーの上でマウス ボタンを押している間、ドラッグ中、メニューが開いている間、バーにキーボード フォーカスがある間。
- ブラウザーをクリックして Windows の設定が開いた後は、設定画面の操作を邪魔しないようにバーは通常どおり収納されます。既定の変更の確認は裏で続きます。

### 収納されたバーを呼び出す

- **タブにマウスを重ねる**: 少し(約 0.15 秒)留まると展開します。通り過ぎただけでは開きません。
- **タブをクリック** する(キーボードでは Enter)と、すぐに展開します。
- **通知領域アイコンを左クリック** するか、メニューの「BrowserFlip を表示」を選ぶと展開します。

マウスを重ねて開いた場合は、マウスが離れるとまた収納されます。

## 6. 通知領域アイコン

通知領域(タスクバー右端)に BrowserFlip のアイコンが表示されます(既定で ON)。アイコンにマウスを重ねると、現在の既定のブラウザーが表示されます。

- **左クリック**: BrowserFlip を表示します(コンパクトバー使用中はバーを展開します)。
- **右クリック**: メニューを表示します。

| メニュー項目 | 動作 |
| --- | --- |
| BrowserFlip を表示 | 通常画面を表示(コンパクトバー使用中はバーを展開) |
| 常に手前に表示 | 最前面表示の切り替え |
| コンパクトバー | 通常画面とコンパクトバーの切り替え |
| 画面端にドッキング | ドッキングの切り替え |
| ドッキング位置 | 左 / 右 / 上 / 下 |
| 自動的に隠す | 自動的に隠すの切り替え(ドッキング中のみ選択可) |
| 設定… | 通常画面を開き、表示オプションを表示 |
| 終了 | BrowserFlip を終了 |

- 通常は、通常画面を閉じる(× ボタン)と BrowserFlip は **終了** します。
- 表示オプションの「ウィンドウを閉じても通知領域で動作を継続」を ON にすると、閉じても終了せず通知領域に残ります。この項目は「通知領域にアイコンを表示」が ON のときだけ選べます。終了するにはメニューの「終了」を使います。
- 「通知領域にアイコンを表示」を OFF にしても、すべての機能は通常画面とコンパクトバー(右クリック メニュー)から使えます。
- エクスプローラーが再起動しても、アイコンは自動的に再表示されます。

## 7. 設定の保存場所とリセット

- 設定は次のファイルに自動保存されます(変更するたびに保存)。

  ```text
  %LOCALAPPDATA%\BrowserFlip\settings.json
  ```

- 保存される内容: 言語、テーマ、表示モード(通常 / コンパクト)、常に手前に表示、ドッキングの有無・端・位置・モニター、自動的に隠す、バーのサイズと向き、通知領域アイコンの設定、通常画面とバーの位置・大きさ。
- **リセット方法**: BrowserFlip を終了してから `settings.json` を削除します。次回起動時はすべて既定値(通常画面、最前面 OFF、ドッキング OFF、通知領域アイコン ON)で起動します。

  ```powershell
  Remove-Item "$env:LOCALAPPDATA\BrowserFlip\settings.json"
  ```

- ファイルの一部の値が壊れていても、その項目だけが既定値に戻り、ほかの設定は維持されます。v0.1 の設定ファイルもそのまま使えます。
- BrowserFlip はこのファイル以外に書き込みを行わず、レジストリも変更しません。

## 8. トラブルシューティング

**コンパクトバーが見えない / どこにあるか分からない**

1. 通知領域アイコンを左クリックするか、右クリックして「BrowserFlip を表示」を選びます。
2. 画面の端に細いタブがあれば、自動的に隠すで収納されています。タブにマウスを重ねるかクリックしてください。
3. 通知領域アイコンも表示していない場合や、それでも見つからない場合は、BrowserFlip を終了(タスク マネージャーから終了してもかまいません)し、`settings.json` を削除してから起動し直してください(§7)。通常画面で起動します。

**モニターを外したらウィンドウが消えた**

モニターの接続・切断、解像度・拡大率の変更、スリープからの復帰、タスクバーの位置変更の後は、BrowserFlip が自動的に画面内に配置し直します。表示されない場合は上と同じ手順で呼び出してください。

**最前面にしているのに、他のウィンドウの後ろに隠れる**

全画面のアプリやプレゼンテーションの実行中は、最前面表示が一時的に解除されます(仕様です)。全画面を終えると、約 1 秒以内に最前面に戻ります。

**最大化したウィンドウにバーが重なる**

ドッキングしたバーは画面の表示領域を予約しないため、ほかのウィンドウの上に重なります。気になる場合は「自動的に隠す」を ON にするか、バーを別の端やモニターに移してください。

**バーがすぐに隠れてしまう / 隠れない**

自動的に隠すは、マウスがバーから離れて約 0.6 秒後に収納します。バーにキーボード フォーカスがある間やメニューを開いている間は収納されません。収納しないようにするには、「自動的に隠す」を OFF にします。

**× ボタンで閉じたのに通知領域に残っている**

「ウィンドウを閉じても通知領域で動作を継続」が ON になっています。完全に終了するには、通知領域アイコンを右クリックして「終了」を選びます。

**設定画面から戻ってもバッジが変わらない**

コンパクトバー使用中は、変更が約 1.5 秒間隔の確認で反映されます。少し待つか、通常画面に戻って「再読み込み」(F5)をしてください。そのほかの問題は [README](../README.ja.md) の「よくある質問」を参照してください。

## 9. キーボード操作

| 場所 | キー | 動作 |
| --- | --- | --- |
| 通常画面 | Tab / Shift+Tab | カードやボタンの間を移動 |
| 通常画面 | Enter / Space | 選択中のカード・ボタンを実行 |
| 通常画面 | F5 | 再読み込み |
| コンパクトバー | Tab / Shift+Tab | バーのボタン・ブラウザーの間を移動 |
| コンパクトバー | Enter / Space | 選択中のボタンを実行 |
| コンパクトバー | アプリケーション キー / Shift+F10 | メニューを開く |
| 収納時のタブ | Enter / Space | バーを展開 |
| メニュー | ↑ / ↓、Enter、Esc | 項目の選択、実行、閉じる |
| 通知領域 | Win+B → 矢印キーで BrowserFlip を選択 → Enter | BrowserFlip を表示 |
| 通知領域 | Win+B → 選択 → アプリケーション キー / Shift+F10 | メニューを開く |

バーにキーボード フォーカスがある間は、自動的に隠す機能は収納しません。
