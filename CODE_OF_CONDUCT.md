# Code of Conduct / 行動規範

## English

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its Code of Conduct. Translations are available at <https://www.contributor-covenant.org/translations/>.

All participants in BrowserFlip spaces — issues, pull requests, discussions and any other project channels — are expected to follow it.

### Our pledge (summary)

We pledge to make participation in our community a harassment-free experience for everyone, regardless of age, body size, visible or invisible disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, caste, color, religion, or sexual identity and orientation. We act and interact in ways that contribute to an open, welcoming, diverse, inclusive, and healthy community.

The full text of the Contributor Covenant 2.1 is the authoritative version.

### Reporting

To report unacceptable behavior, contact the project maintainers privately. Use GitHub's **Report content** feature on the relevant comment, issue or pull request, or open a private report through the repository's **Security** tab → **Report a vulnerability** and state that it concerns the Code of Conduct. Please do not report conduct issues in public threads.

All reports will be reviewed and investigated promptly and fairly. Maintainers are obligated to respect the privacy and security of the reporter. Enforcement follows the Contributor Covenant 2.1 [Enforcement Guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines) (Correction, Warning, Temporary Ban, Permanent Ban).

## 日本語

本プロジェクトは [Contributor Covenant 2.1](https://www.contributor-covenant.org/ja/version/2/1/code_of_conduct/) を行動規範として採用しています。Issue、Pull Request、Discussion などプロジェクトのあらゆる場で、すべての参加者はこれに従ってください。

受け入れられない行為の報告は、該当コメント等の GitHub の **Report content** 機能、またはリポジトリの **Security** タブ → **Report a vulnerability**(行動規範に関する報告である旨を明記)から、非公開でメンテナーに連絡してください。正式な規範は Contributor Covenant 2.1 の全文です。
